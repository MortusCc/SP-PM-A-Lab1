# 软件配置管理实验 - Git 版本控制实践仓库

## 项目简介

本仓库是“软件过程与项目管理A”课程实验1的实践代码仓库。本实验旨在通过 Git 工具的安装、配置和应用，学习并掌握软件配置管理中的版本控制、分支管理与远程协作。

本仓库完整包含了实验要求的 R0~R18 所有操作步骤的最终成果，演示了从本地仓库初始化、文件提交、分支创建、冲突合并到远程推送的完整 Git 工作流。

## 文件清单

根据实验要求，本仓库包含不少于 5 个源文件（或文档），用于演示版本控制过程：

- `file1.txt` —— 实验演示文件 1（被多次修改并产生冲突）
- `file2.txt` —— 实验演示文件 2（被多次修改并产生冲突）
